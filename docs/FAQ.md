# FAQ

**Нужен ключ?** Нет. Сборка keyless.

**Сколько UNC?** ~59% sUNC / 76% UNC. Большинство популярных скриптов идут, часть нет — Solara external, потолок ниже чем у платных internal.

**Безопасно для аккаунта?** Нет гарантий. Roblox банит за сторонние executors. Играй с альтов.

**Windows / Mobile?** Этот репо — Windows 10/11 x64. Мобильных сборок Solara в этой линейке нет, все «APK Solara» — сторонние.

**Откуда качать безопасно?** Только Releases этого репо + getsolara.dev. Остальное — ре-аплоады с риском малвари.

**Исходники?** Оригинал закрыт (CMD Softworks). Здесь — дистрибуция, скрипты установки, доки и примеры Lua.
